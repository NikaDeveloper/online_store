# 🛒 Skystore: Интернет-магазин цифровых товаров

## Описание проекта

**Skystore** — это учебный проект интернет-магазина, созданный в рамках курса по Django. Проект предназначен для продажи цифровых товаров, таких как плагины, боты и веб-приложения.

На текущем этапе реализована **базовая структура** Django-проекта, настроена маршрутизация (URL-адреса) и созданы шаблоны для главных страниц.

---

## 🚀 Используемые технологии

* **Фреймворк:** Python (Django 5.x)
* **Стилизация:** Bootstrap 5
* **Управление зависимостями:** Poetry (или `pyproject.toml`)
* **Система контроля версий:** Git / GitHub

---

## 🛠️ Установка и запуск

Для запуска проекта локально выполните следующие шаги.

### 1. Клонирование репозитория

```bash
    git clone git@github.com:NikaDeveloper/online_store.git
    cd online_store 
```

### 2. Установка зависимостей и окружения
Проект использует Poetry для управления зависимостями.

# Установка зависимостей (если используете Poetry)
```bash
  poetry install
```

# Активация виртуального окружения
```bash
  poetry shell
```

(Если вы используете venv и requirements.txt, замените эти команды на активацию venv и pip install -r requirements.txt)

### 3. Запуск сервера
```bash
    python manage.py runserver
```
Проект будет доступен по адресу: http://127.0.0.1:8000/
