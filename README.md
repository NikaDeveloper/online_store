# 🛒 Skystore: Интернет-магазин цифровых товаров

## Описание проекта
Skystore — это учебный проект интернет-магазина, созданный в рамках курса по Django. Проект предназначен для продажи цифровых товаров, таких как плагины, боты и веб-приложения.

Включает в себя полноценный каталог товаров с пагинацией и детальными страницами, отдельный раздел "Блог" с полным CRUD-функционалом, а также **полноценную систему управления пользователями и аутентификацией**.

***

### 🚀 Используемые технологии
* Backend: **Python**, **Django 5.x**
* Frontend: HTML, Bootstrap 5
* База данных: PostgreSQL
* Управление зависимостями: Poetry, **python-dotenv**
* Контроль версий: Git / GitHub

***

### 🛠️ Установка и запуск

Для запуска проекта локально выполните следующие шаги.

1. Клонирование репозитория
```bash
    git clone git@github.com:NikaDeveloper/online_store.git
    cd online_store
```
2. Установка зависимостей и окружения Проект использует Poetry для управления зависимостями.

```bash
    poetry install
    poetry shell
```
3. Настройка переменных окружения: Проект использует файл .env для хранения чувствительных данных (ключи, логины/пароли для почты). 
Создайте файл .env в корне проекта и заполните его:
### .env
* SECRET_KEY='ВАШ_СЕКРЕТНЫЙ_КЛЮЧ'
* EMAIL_HOST_USER='ВАШ_ЛОГИН_ПОЧТЫ'
* EMAIL_HOST_PASSWORD='ВАШ_ПАРОЛЬ_ПРИЛОЖЕНИЯ'

4. Применение миграций 
Создайте базу данных и примените исходные миграции:

```bash
    python manage.py migrate
```
Запуск сервера
```bash
    python manage.py runserver
```
Проект будет доступен по адресу: http://127.0.0.1:8000/

✨ Функционал проекта
**Каталог товаров (catalog)**
* Просмотр списка товаров: Главная страница отображает все товары с пагинацией.

* Детальная страница товара: У каждого товара есть собственная страница с полным описанием.

* Страница контактов: Статичная страница с контактной информацией.

* Ограничение доступа: Страницы создания, редактирования и удаления товаров доступны только авторизованным пользователям (LoginRequiredMixin).

* Реализация на Class-Based Views: Все контроллеры каталога (ListView, DetailView) построены на классах.

**Управление пользователями (Users) 🆕**
* Кастомная модель пользователя: Основана на AbstractUser, использует Email в качестве логина и содержит дополнительные поля: аватар, номер телефона, страна.

* Регистрация: Пользователи могут пройти регистрацию; после успешной регистрации отправляется приветственное email-сообщение (настройка почты вынесена в .env).

* Авторизация/Выход: Реализован полный цикл входа и выхода.

* Обновление профиля: Авторизованные пользователи могут обновлять свои персональные данные.

**Блог (blog)**
* CRUD-функционал: Реализованы все операции для управления статьями.

* Публикация: В списке отображаются только статьи с флагом "Опубликовано".

* Счётчик просмотров: При каждом просмотре детальной страницы статьи счётчик увеличивается на 1.

* Email-уведомление: При достижении 100 просмотров отправляется автоматическое уведомление.

* Динамические URL: Для страниц статей используются человеко-понятные URL (slug).
