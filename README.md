# 🛒 Skystore: Интернет-магазин цифровых товаров

### Описание проекта

**Skystore** — это учебный проект интернет-магазина, созданный в рамках курса по Django. Проект предназначен для продажи цифровых товаров, таких как плагины, боты и веб-приложения.

Включает в себя полноценный каталог товаров с пагинацией и детальными страницами, а также отдельный раздел "Блог" с полным CRUD-функционалом для управления статьями.

### 🚀 Используемые технологии

  - **Backend**: Python, Django 5.x
  - **Frontend**: HTML, Bootstrap 5
  - **База данных**: PostgreSQL 
  - **Управление зависимостями**: Poetry
  - **Контроль версий**: Git / GitHub

### 🛠️ Установка и запуск

Для запуска проекта локально выполните следующие шаги.

**1. Клонирование репозитория**

```bash
git clone git@github.com:NikaDeveloper/online_store.git
cd online_store
```

**2. Установка зависимостей и окружения**
Проект использует Poetry для управления зависимостями.

*Установка зависимостей:*

```bash
poetry install
```

*Активация виртуального окружения:*

```bash
poetry shell
```

**3. Применение миграций**
Создайте базу данных и примените исходные миграции:

```bash
python manage.py migrate
```

**4. Запуск сервера**

```bash
python manage.py runserver
```

Проект будет доступен по адресу: **[http://127.0.0.1:8000/](http://127.0.0.1:8000/)**

### ✨ Функционал проекта

#### Каталог товаров (`catalog`):

  - **Просмотр списка товаров**: Главная страница отображает все товары с пагинацией (постраничным выводом).
  - **Детальная страница товара**: У каждого товара есть собственная страница с полным описанием.
  - **Страница контактов**: Статичная страница с контактной информацией.
  - **Реализация на Class-Based Views**: Все контроллеры каталога (`ListView`, `DetailView`) построены на классах для лучшей читаемости и расширяемости.

#### Блог (`blog`):

  - **CRUD-функционал**: Реализованы все операции для управления статьями:
      - **C**reate (создание)
      - **R**ead (чтение списка и отдельных статей)
      - **U**pdate (редактирование)
      - **D**elete (удаление)
  - **Публикация**: В списке отображаются только статьи с флагом "Опубликовано".
  - **Счётчик просмотров**: При каждом просмотре детальной страницы статьи счётчик увеличивается на 1.
  - **Email-уведомление**: При достижении 100 просмотров на почту, указанную в `settings.py`, отправляется автоматическое уведомление.
  - **Динамические URL**: Для страниц статей используются человеко-понятные URL (`slug`), которые генерируются автоматически из заголовка при создании записи.

  - `catalog/`: Приложение, отвечающее за каталог товаров и страницу контактов.
  - `blog/`: Приложение для управления блогом.
